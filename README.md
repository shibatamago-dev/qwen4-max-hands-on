# Qwen4-Max × Gemini 4 Hydrogen — ゲーム制作課題の再現リポジトリ

Alibaba **Qwen4-Max**（2026-11-16 GA）と **Gemini 4 Hydrogen** に、まったく同じプロンプトで「単一HTMLファイルのダンジョン探索ゲーム」を作らせ、生成物を実際に動かして検証したときの再現資料です。

Zenn記事: （下書き済み・公開後にリンクを追記）

## 課題

`prompt.txt` のプロンプトを、各モデルに1回だけ送信しました。必須仕様は次の7項目です。

1. 10×10マップを毎回ランダム生成（壁・床・出口）
2. 矢印キー/WASDと、スマホ用の画面ボタンで移動
3. 敵3体がプレイヤーの移動後に1マスずつ追跡し、接触するとHP制の戦闘
4. 回復アイテム2個（拾うとHP回復）
5. 出口到達で次の階へ進み、3階クリアでゲームクリア
6. HPが0でゲームオーバー。階層と撃破数のスコアを常時表示
7. リスタートボタン

## 条件（経路が違うので完全な同一条件ではありません）

| | Qwen4-Max | Gemini 4 Hydrogen |
|---|---|---|
| 経路 | Qwen Chat 無料プラン（ログイン後にピッカーで選択可） | Gemini API（AI Studioキー、無料枠） |
| 設定 | すべてデフォルト（モード「自動」） | 温度0、thinkingLevel high |
| 出力上限 | チャット側デフォルト（非公開） | maxOutputTokens 65536 |
| 送信回数 | 1回 | 1回 |

## 結果

| | Qwen4-Max | Gemini 4 Hydrogen |
|---|---|---|
| コード規模 | 1,196行 / 65,716バイト | 798行 / 23,291バイト |
| 仕様7項目 | すべて実装 | すべて実装 |
| 実行検証 | スタブ環境で起動・入力・戦闘・回復・B2F到達・リスタート確認 | 同左＋ゲームオーバー画面まで実到達 |
| 外部依存 | なし | なし |

詳細は `RESULTS.md` を参照してください。

## ファイル

- `prompt.txt` — 両モデルに送ったプロンプト（同一文面）
- `qwen4-max_game.html` — Qwen4-Maxの生成物（Qwen Chatのダウンロード機能で取得したファイルを正本とする）
- `hydrogen_game.html` — Hydrogenの生成物（API応答のコードブロックから抽出）
- `hydrogen_raw.json` — Hydrogen APIの生レスポンス（usageMetadata含む）
- `hydrogen_run.py` — Hydrogen呼び出しスクリプト（認証はMuseのコネクタ経由のサロゲートで、キー自体は含まれません）
- `game_script.js` / `hydrogen_script.js` — 各生成物から抽出したJS（構文チェック・ハーネス用）
- `test_harness.js` — Qwen生成物用の検証ハーネス（Node.js、DOMスタブ＋仮想時計＋シード付き乱数）
- `test_harness_hydrogen.js` — Hydrogen生成物用の検証ハーネス（同方式）

## 検証の前提と限界

- 検証はNode.js上のDOMスタブ環境での実行です。実ブラウザではありません
- 見た目（スマホ幅390pxでのレイアウト崩れなど）は未確認です
- クリア画面は両モデルとも実プレイ未到達で、コード確認のみです
- 実行時間の類いは環境依存のため、モデル速度の比較には使っていません（記録の扱いは `RESULTS.md` 参照）

## 検証の実行方法

```bash
node test_harness.js            # Qwen側
node test_harness_hydrogen.js   # Hydrogen側
```

## 注意：Qwen Chatの表示について

Qwen Chatのコードブロックは、生成直後に見た先頭部分と、後から開き直したときの先頭部分が異なる内容に変わって見える現象がありました（原因は特定できていません。再生成は行っていません）。ダウンロードで取得したファイルは2回とも完全に同一だったため、本リポジトリではそちらを正本としています。
